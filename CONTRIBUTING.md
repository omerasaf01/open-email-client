# Contributing / Katkıda Bulunma

Thanks for your interest in contributing! / Katkıda bulunduğunuz için teşekkürler!

## How to contribute
- Fork the repo and create a branch: `feature/your-short-desc`.
- Open a pull request from your branch to `main` with a clear description.

## Pull request checklist
- [ ] My changes are small and focused.
- [ ] I updated related documentation (including translations where relevant).
- [ ] I added/updated tests where appropriate.
- [ ] CI passes (if present).

## Coding standards
- Keep C# code in `OpenEmail-Backend` idiomatic and formatted.
- Frontend (Next.js) should use TypeScript and follow common linting rules (ESLint, Prettier).

## Language and translations
- Add translation keys under `OpenEmail-Frontend/locales/en` and `.../tr`.
- When adding new UI text, include both English and Turkish entries if possible.

## Reporting issues
- Use issue templates when filing bugs or feature requests to provide context.

If you want me to scaffold the Next.js frontend or add CI workflows, tell me and I'll proceed.
